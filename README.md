# LLM Serving Lab

**Kubernetes에서 LLM 서빙의 종료·교체 안정성을 재현하고 검증하는 프로젝트입니다.**

## 작업 흐름

브레인스토밍으로 설계하고 리뷰한 뒤, 독립적으로 검증할 수 있는 PR 단위로 나눕니다. 각 PR을 구현·테스트·리뷰·머지하고, 결과에서 지속적으로 필요한 지식을 OpenWiki에 반영합니다.

상세 절차는 [개발 작업 흐름](.harness/workflow.md)을 참고하세요.

## 문서 안내

[AGENTS.md](AGENTS.md)는 공통 규칙과 문서 탐색의 진입점입니다. 이 README는 AGENTS.md와 관련 하네스·위키 문서를 바탕으로 사람이 읽기 쉽게 정리합니다.

설계·계획 등의 `docs/` 자료는 관련 하네스 또는 위키에 반영된 뒤 README에 소개합니다.
