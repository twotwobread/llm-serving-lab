# 현재 상태와 미결정 사항

기준: 2026-10-21. 상태는 코드·설정·검증 결과와 대조하여 갱신한다.

- 현재 저장소에는 문서, 에이전트 연동 설정, upstream 스킬 사본과 .gitignore가 있다. Operator, CRD, faker, 배포 자동화, 테스트는 아직 구현되지 않았다.
- 언어·프레임워크, Kubernetes 배포판, 실제 추론 엔진, 관측·저장 제품, API 스키마, 부하 도구, 성공 임계값은 미확정이다.
- 서빙 프로젝트의 빌드·테스트·실행 명령은 아직 없다. 존재하지 않는 명령이나 설치 방법을 문서에 작성하지 않는다.
- 구현 진행 시 이 문서의 상태를 갱신하고, 실행 명령과 환경 조건은 [개발 환경](development.md), 에이전트 설정은 [도구 설정](agent-tooling.md)에 유지한다.
- OpenWiki 설정과 upstream 스킬은 추가되어 있지만 위키 생성은 아직 수행하지 않았다.
- 초기 설계 방향은 문서로 남았으며 상세 설계 리뷰와 PR 단위 계획은 아직 작성하지 않았다.

설계는 [초기 설계 문서](superpowers/specs/2026-10-21-serving-reliability-design.md)를 참조한다.
