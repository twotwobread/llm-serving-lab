# 개발 환경과 실제 GPU 검증

상태: 합의한 환경 구성 방향. 실행 환경과 자동화는 아직 구현되지 않았다.

- 일상 개발: 로컬 Kubernetes와 가짜 추론 서버(faker). 로딩 지연, 긴 스트리밍, 정상 종료·비정상 종료를 재현한다.
- faker는 실험·판정 도구의 검증 수단이다. 그 결과를 실제 추론 엔진의 동작 증거로 취급하지 않는다.
- 실제 검증: 필요한 시점에 GPU VM을 빌려 독립된 Kubernetes 클러스터를 구성한다. TensorDock는 검토한 후보이며 사용 가능 구성과 비용은 실행 시 확인한다.
- 로컬 클러스터에 원격 GPU 노드를 조인하는 구조는 초기 범위에 포함하지 않는다.
- 동일한 Operator와 환경별 설정을 사용한다. 초기화 자동화는 GPU 실행 환경, Kubernetes, device plugin, Operator, 관측 구성 배포를 다룬다.
- 결과를 VM 외부에 보관한 뒤 임시 GPU 자원을 정리한다.


실제 구현 후 실행 명령, 사전 조건, 환경별 검증 범위를 이 문서에 갱신한다. 없는 명령을 추정해서 작성하지 않는다.

에이전트 도구 실행 환경은 [도구 설정](agent-tooling.md)을 참조한다.
