# 위키 작성 범위

한국어로 작성한다. 코드 식별자와 명령은 원문을 유지한다.

- README를 읽거나 근거로 사용하지 않는다.
- 하네스는 작업 지침이고 위키는 프로젝트 지식이다. 하네스의 규칙을 복제하거나 자동 변경하지 않는다. 공식 도구의 AGENTS 관리 블록 외에는 하네스를 수정하지 않는다.
- docs는 미검증 입력이다. 세션에서 확인된 사용자 결정과 실제 저장소의 코드·설정·테스트를 대조한 내용만 반영한다.
- 이번 초기화는 합의한 서빙 실험 목적·책임 분리·개발 환경 방향과 현재 에이전트 설정을 다룬다. 설계 합의와 구현된 동작을 명확히 구분한다. 아직 Operator·CRD·faker·GPU 실험 구현이나 실행 증거가 없다.
- 세션의 초기 설계 합의 확인은 실행 검증을 뜻하지 않는다. 미결정 API, 성공 임계값, 엔진과 인프라 선택을 확정된 것으로 기술하지 않는다.
- 책임·관계·중요한 결정 이유·검증 범위를 중심으로 작성하고 작업 목록이나 논의 전체를 복제하지 않는다.
- 기존 기준 페이지를 갱신하고 다른 페이지는 링크한다. 하네스에서는 docs 개별 문서로 링크하지 않는다. 위키의 출처 추적은 OpenWiki의 Claims로 유지한다.
- 검증 완료 메타데이터가 실제 GPU 동작 검증을 뜻하는 것처럼 설명하지 않는다.
